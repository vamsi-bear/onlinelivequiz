# Online Live Quiz

## Description
A Firebase-based Android quiz application that allows students
to participate in quizzes and view results and leaderboards.

## Technologies
- Java
- XML
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Firebase Realtime Database
- RecyclerView

## Features
- Student registration and login
- Admin quiz creation
- Timed quizzes
- Multiple-choice questions
- Automatic score calculation
- Attempt tracking
- Real-time leaderboard
- Admin leaderboard view
